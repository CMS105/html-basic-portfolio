About Me

I'm Chirag, a second-year B.E. student specializing in Artificial Intelligence and Machine Learning at The National Institute of Engineering (NIE), Mysuru. I'm passionate about exploring how intelligent systems can solve real-world problems, and I enjoy the process of turning technical concepts into working projects.

My project work spans computer vision and deep learning — from an AI Liveness Detection system built with Python, OpenCV, and Dlib, to an IPBL project on AI Synthetic Media Detection, where I built a CNN-based fake image classifier using Google's Teachable Machine and a Flask/TensorFlow backend. Beyond academics, I'm part of the Event Management Core team at the OWASP NIE Student Chapter, where I help plan and host technical and non-technical events for the student community.

I'm currently deepening my foundations in data structures and algorithms while continuing to build AI/ML projects, with the goal of contributing to impactful software and AI-driven products.
